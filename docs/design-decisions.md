# Решения и правила

Что решили и почему. Эти правила проверяются в брендбуке (раздел «Правила») и частично сборкой.

## Решения

| Вопрос | Решение |
|---|---|
| Цвет | Янтарь `#FFB020` и нейтрали. Светлая тема: бумажный холст `#F3F4F2`, белые карточки. Тёмная: почти чёрная `#09090A`. Тёмные острова (сайдбар, баннеры) в обеих темах |
| Акцент | Янтарь основной. Золото брендбука `#D2A852` осталось слотом `product.gold` для сравнения |
| Шрифты | Tektur (заголовки от 20 px, цифры), IBM Plex Sans (интерфейс), IBM Plex Mono (ID, суммы). Как в направлении «Магистраль» |
| Формы | Кнопки, поля, чипы, вкладки pill. Блок в карточке и textarea 16. Карточки 24. Острова и баннеры 32. Вложенный радиус = внешний минус отступ, не меньше 6 |
| Кнопки | default (янтарь), cta (остров), secondary, outline, ghost, destructive. Высоты 36, 44, 48, водитель 56. Плоские: без обводок, блеска и объёма. Нажатие 0,96 |
| Сетка карточек | Однотипные карточки в ряду одного размера. Разные виды (раздел «Карточки») имеют размер по смыслу и собираются в bento-сетку. S, M, L меняют размер сетки и содержимого, включая заливку |
| Чипы статуса | Тёмный текст и цветная точка. У критичных ещё иконка. Цвета для AI нет: подпись «Предложение AI» и искра |
| Сайдбар | Остров 240 px, рельса 64 (сворачивание мгновенное), активная вкладка вырастает из холста с вогнутыми углами (260 мс), портрет сокола внизу |
| Сокол | Везде: сайдбар, водяной знак, пустые состояния, загрузчик, аватар, баннер. Логотип только исходный SVG |
| Подсказки | Один вид для всех, один скрипт, не обрезаются контейнерами |
| Движение | Только `transform` и `opacity`, плюс короткие переходы цвета. Кривые и длительности только из токенов |
| Продукты | Общее ядро и свой акцент через слот `product` |

## Чего нельзя

| Нельзя | Почему |
|---|---|
| Тёмно-синие и фиолетовые фоны | Выглядят как шаблон «нейрослоп». Тёмная тема нейтральная, почти чёрная |
| Градиенты в фонах | Единственное исключение: маска у shimmer |
| Янтарный текст на светлом | Не проходит контраст. Янтарь только заливка, рамка и иконка |
| Белый текст на янтаре | Не проходит контраст. Текст на янтаре всегда `#14110A` |
| Цвет для AI | AI это подпись и искра, а не отдельный цвет |
| Обводки, блеск и объём на кнопках | Минимализм: только плоская заливка |
| Tektur мельче 20 px и для обычного текста | Он для заголовков и цифр |
| Растянутый, обведённый или светящийся логотип | Логотип только исходный SVG, 3D-сокола нет |
| `transition: all` | Анимируются только нужные свойства |
| Анимация высоты и ширины | Перерасчёт раскладки. Используйте `transform` и `opacity` |
| Однотипные карточки разного размера в одном ряду | Ряд должен читаться как сетка |
| Нативные подсказки `title`, нативный `select` | Единый стиль: `data-tip` и `fa-select` |

## Движение

- Нажатие: `scale(0.96)` за 120 мс. Меньше 0,95 не используется.
- Появление быстрое и на `ease-out`. `ease-in` для интерфейса не применяется.
- Hover включается только на устройствах, которые умеют наводиться (`@media (hover: hover) and (pointer: fine)`), чтобы на телефоне он не «залипал».
- Действия, которые пользователь повторяет сотни раз (например, палитра Ctrl K), не анимируются. Список, открытый с клавиатуры, появляется без анимации.
- Всплывающие элементы растут из своего триггера (`transform-origin`), модальные остаются по центру.
- Нижний лист: 320 мс на `ease-drawer`, закрытие быстрее (220 мс), быстрый жест закрывает на любом расстоянии.
- При `prefers-reduced-motion`: вкладка сайдбара и лист уходят в плавное появление, shimmer и загрузчик в мягкий пульс.

## Размеры и адаптив

Точки: до 560 px (один столбец, переключатель размера скрыт), до 760 px (сайдбар становится панелью по кнопке), 761-1100 px (планшет), от 1100 px. Минимальная зона нажатия 44 px (на устройствах с касанием), главная кнопка водителя 56 px. Содержимое карточек не увеличивается через S, M, L на узких экранах: колонки там уже тесные.

## Доступность

- Контраст проверяется сборкой: текст 4,5:1, граница контрола, фокус и точка статуса 3:1.
- Кольцо фокуса видно на светлом и на островах (отдельный токен `island-focus`).
- Состояние никогда не передаётся только цветом: у чипа есть текст, у критичного ещё иконка.
- Все интерактивные компоненты работают с клавиатуры.

## Источники правил

Единый визуал Falcon, правила форм, сайдбара, токенов, skeleton и движения взяты из внутренней базы знаний проекта (GAIM, Private) и из текущего интерфейса Agents.
