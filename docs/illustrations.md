# Иллюстрации

128 плоских иллюстраций **FAI-001 ... FAI-128**, нарисованных с нуля для продуктов Falcon. Все утверждены владельцем. Лежат в [`assets/illustrations/`](../assets/illustrations).

```
assets/illustrations/svg/                       SVG с переменными --illustration-* (для inline)
assets/illustrations/light/                     готовая светлая палитра для обычного <img src>
assets/illustrations/dark/                      готовая тёмная палитра для обычного <img src>
assets/illustrations/illustrations.json         каталог: сюжет, раздел, продукт, состояние, ограничения, связанные позиции
assets/illustrations/illustrations.bundle.json  разметка всех SVG одним файлом (для брендбука и скриптов)
assets/illustrations/fixes/                     правки владельца, перекрывают исходник при синхронизации
```

## Как использовать

### Вариант 1: inline SVG (рекомендуется)

Иллюстрация подхватывает цвета кита и сама переключается между светлой и тёмной темой.

```html
<span class="fa-illu" aria-hidden="true">
  <!-- содержимое assets/illustrations/svg/FAI-017.svg -->
</span>
```

В SVG цвета заданы переменными с запасным значением:

| Переменная | Роль | Токен кита |
|---|---|---|
| `--illustration-ink` | Контур и тёмные детали | `color-text` |
| `--illustration-fill` | Основная заливка | смесь текста и карточки |
| `--illustration-muted` | Светлые поверхности | `color-inset` |
| `--illustration-accent` | Акцент | `color-accent` |
| `--illustration-paper` | Бумага, белые элементы | `color-card` |
| `--illustration-skin` | Телесный цвет | `color-illu-skin` |

Класс `fa-illu` связывает эти переменные с токенами. Фрагмент можно переключить на остров: `fa-illu fa-illu--island`.

### Вариант 2: обычный `<img>`

Внутри `<img src>` SVG не видит CSS-переменных, поэтому для него есть готовые варианты:

```html
<img src="/falcon/assets/illustrations/light/FAI-017.svg" alt="">
<img src="/falcon/assets/illustrations/dark/FAI-017.svg" alt="">
```

Выбирайте папку по теме. Для автоматического переключения используйте `<picture>` с `prefers-color-scheme`.

### Доступность

Рисунок рядом с текстом декоративный: `aria-hidden="true"` и пустой `alt`. Если рисунок один несёт смысл, добавьте `role="img"` и `aria-label` с названием из каталога.

## Слоты и пустые состояния

Контейнеры задают форму, иллюстрация вписывается в неё:

```html
<div class="fa-slot fa-slot--square">...</div>   <!-- квадрат -->
<div class="fa-slot fa-slot--wide">...</div>     <!-- горизонталь 16:9 -->
<div class="fa-slot fa-slot--tall">...</div>     <!-- вертикаль 3:4 -->

<div class="fa-state">
  <span class="fa-illu fa-state__art">...</span>
  <h3 class="fa-state__title">Очередь пуста</h3>
  <p class="fa-state__text">Нет задач, которые требуют решения.</p>
  <div class="fa-state__actions">...</div>
</div>
```

## Каталог

`illustrations.json` описывает каждую позицию:

| Поле | Смысл |
|---|---|
| `id`, `title` | FAI-NNN и название |
| `scenario` | Сюжет и место применения |
| `section`, `sectionTitle` | Раздел каталога (1-15) |
| `kind` | Тип экрана: hero, onboarding, empty, media, error, auth, file, team, domain |
| `product` | Для какого продукта: Криптобанк, CRM грузоперевозок, Платформа найма, Vitrino, Agents, Агрегатор моделей, AI-маркетинг или все |
| `state` | Состояние рисунка: пусто, проблема, успех, ожидание, сведения |
| `limits` | Ограничения использования из каталога |
| `related` | Пары, которые нельзя путать |
| `roles` | Какие цвета-роли использует рисунок |

Ограничения читайте обязательно: например, цифры, тексты и причины ошибок рисует интерфейс, а не иллюстрация.

## Брендбук

Раздел «Иллюстрации» (`npm start`):

- каталог: поиск, фильтр по разделу, карточки;
- сценарии: таблица всех 128 позиций с продуктом, сценарием и ограничениями;
- палитры: текущая, светлая, тёмная, остров, золото;
- страница каждой иллюстрации: сюжет, ограничения, «не путать с», скачивание SVG, светлой и тёмной версии, живые экраны на телефоне, планшете и ноутбуке для каждого сценария (hero, онбординг, пустое состояние, слоты, страница ошибки, вход, диалог, боковая панель и другие).

## Обновление набора

Каталог и исходные SVG ведёт отдельная папка (`illustrations/` с `ILLUSTRATION-CATALOG.md` и `svg/FAI-NNN-illustration.svg`). Чтобы обновить кит:

```bash
npm run build
npm run sync:illustrations -- --src путь/к/illustrations
```

Скрипт:

1. читает каталог и копирует SVG;
2. префиксует `id` внутри каждого SVG (иначе 128 inline-SVG на одной странице конфликтуют);
3. проверяет `viewBox` и запрещённое содержимое: растры, скрипты, фильтры, градиенты, анимации, текст внутри рисунка;
4. собирает `illustrations.json`, `illustrations.bundle.json` и запечённые варианты `light/` и `dark/` по цветам из `dist/tokens.flat.json`;
5. заменяет SVG файлами из `assets/illustrations/fixes/`, если они есть.

При проблемах скрипт выводит список и завершается с кодом 1. Сначала выполните `npm run build`, чтобы был актуальный `dist/tokens.flat.json`.

### Правки отдельной иллюстрации

Положите исправленный SVG в `assets/illustrations/fixes/FAI-NNN.svg` (исходный формат, id без префикса) и запустите синхронизацию. Сейчас там лежат:

| Файл | Что исправлено |
|---|---|
| `FAI-086.svg` | Дальнее переднее колесо грузовика спрятано за кабиной и бампером |
| `FAI-106.svg` | Перерисованы лицо и шея аналитика |

## Правила

- Иллюстрации плоские, без градиентов, фильтров, растров и текста внутри рисунка.
- Цвета только через `--illustration-*`, поэтому рисунок следует теме и акценту продукта.
- Иллюстрация не заменяет текст: заголовок, пояснение и кнопки пишет интерфейс.
- Для пустых состояний, ошибок, онбординга и входа берите рисунок из подходящего раздела каталога (поле `kind`), а не по внешнему сходству.
