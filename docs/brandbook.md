# Брендбук

Приложение в папке [`preview/`](../preview) показывает и проверяет всю систему. Запуск: `npm start`, адрес `http://localhost:8767/preview/index.html` (см. [getting-started.md](getting-started.md)).

Брендбук построен на самом ките: его оболочка (`fa-shell`, `fa-sidebar`, `fa-toolbar`) это тот же код, что и в документации компонентов. Если в брендбуке что-то выглядит неправильно, это дефект кита.

## Разделы

| Раздел | Что показывает |
|---|---|
| Обзор | Короткая карта системы и числа |
| Цвет | Палитра в карточках (клик копирует hex, Shift копирует `var()`), доли экрана, острова |
| Шрифты | Гарнитуры, шкала, тестер текста |
| Формы | Радиусы и живая вложенность |
| Карточки | 12 видов, у каждого свой skeleton, переключатель S, M, L, режим «Контент» и «Скелетон» |
| Элементы | Кнопки (состояния принудительно), поля, выбор, список, нижний лист, статусы, таблица, уведомления, навигация |
| Движение | Касание, переходы, кривые, замедление 4x, режим «меньше движения» |
| Загрузка | Skeleton, shimmer, постепенная замена |
| Адаптив | Живые окна телефон, планшет, ноутбук, портрет и альбом, любой раздел |
| Сокол | Знак, портрет, где применять |
| Иллюстрации | 128 иллюстраций, сценарии, палитры |
| Дополнительно: Контраст | Все проверки с фильтром |
| Дополнительно: Правила | «Делаем» и «Не делаем» |
| Дополнительно: Установка | Подключение по стекам, слоты продуктов |

## Устройство

```
preview/index.html   оболочка: сайдбар, тулбар, контейнер страницы, палитра Ctrl K
preview/app.js       роутер по hash, список страниц PAGES, страницы и общие помощники
preview/pages2.js    иллюстрации и адаптив
preview/illu.js      загрузка каталога иллюстраций и разметки SVG
preview/screen.html  экраны-сценарии для живых окон (один рисунок в одном контексте)
preview/screen.css, screen.js
preview/app.css      стили самого брендбука (не части кита)
```

Адреса вида `#/раздел/подраздел`, например `#/components/sheet` или `#/illustrations/FAI-086`. Параметр `?embed=1` включает режим встраивания (скрывается лишнее, анимации выключены): так брендбук показывает сам себя в окнах «Адаптива».

### Размер S, M, L

Переключатель меняет две переменные на контейнере страницы:

- `--pv-scale` задаёт число колонок (минимальная ширина карточки умножается на значение);
- `--pv-zoom` масштабирует содержимое карточек, включая заливку.

На узких экранах `--pv-zoom` не применяется.

### Адаптив

Окна это настоящие `iframe` нужной ширины, уменьшенные через `transform: scale()`. Поэтому медиа-запросы внутри работают как на устройстве. Окна не перехватывают прокрутку (`pointer-events: none`). Ширина раскладки пересчитывается только при реальном изменении ширины контейнера, а полоса прокрутки страницы зарезервирована заранее (`scrollbar-gutter: stable`), поэтому раскладка не дёргается.

## Как добавить страницу

1. В `preview/app.js` добавьте запись в массив `PAGES`:

   ```js
   { id: 'charts', t: 'Графики', i: 'code', g: 'Компоненты', sub: [['line', 'Линии'], ['bar', 'Столбцы']] },
   ```

   `i` это имя иконки из `ICONS`, `g` группа в сайдбаре, `sub` вкладки страницы. Чтобы скрыть страницу в группу «Дополнительно», добавьте её `id` в массив `MORE`.

2. Напишите функцию страницы, которая возвращает `{ html, after(root) }`, и зарегистрируйте её в `RENDER`:

   ```js
   function pCharts(sub = 'line') {
     return { html: `${head(pills(P('charts').sub, sub, 'charts'))}<div class="pv-grid" style="--min:300px">...</div>`, after(root) {} };
   }
   RENDER.charts = pCharts;
   ```

3. Используйте классы кита (`fa-card`, `fa-btn`, ...) и помощники брендбука: `pills()` для вкладок, `seg()` для сегментов, `svg(имя)` и `ic(имя)` для иконок, `toast()` для уведомления.
4. Сетки: `pv-grid` (колонки по минимальной ширине, одинаковые карточки), `pv-bento` (карточки разного размера, `--span` и `--rows`), `pv-split` (две равные колонки).
5. Проверьте страницу на S, M, L, в обеих темах и на 390, 768, 1280 px (раздел «Адаптив» показывает все три).

Выпадающие списки, вставленные вручную через `innerHTML`, подхватываются автоматически: роутер вызывает `FaSelect.enhance` после отрисовки.
