# Токены

Единственный источник: [`tokens/tokens.json`](../tokens/tokens.json), формат DTCG. Всё остальное (`dist/css/tokens.css`, Tailwind, Flutter, плоский JSON) собирается из него командой `npm run build`. Править файлы в `dist/` вручную нельзя.

## Три слоя

| Слой | Что это | Кто использует |
|---|---|---|
| `primitive` | Сырая палитра: бумага, чернила, уголь, янтарь, статусы | Только слой semantic |
| `semantic` | Роли цвета с одинаковыми именами в `light` и `dark` | Компоненты и продукты |
| `product` | Переопределения для продукта: **только группа акцента** | Продукт через `data-product` |

Компоненты и продукты используют только semantic-токены. Hex в компонентах не пишется.

## CSS-переменные

Все токены доступны как `--fa-*`. Имена без префикса `--fa-` ниже.

### Шрифты

| Токен | Значение | Где |
|---|---|---|
| `font-display` | Tektur, затем IBM Plex Sans | Заголовки от 20 px, цифры и KPI |
| `font-sans` | IBM Plex Sans | Интерфейс |
| `font-mono` | IBM Plex Mono | ID, суммы, код |

Шкала (`text-{имя}-size`, `-line`, `-weight`, `-family`). Каждому имени соответствует класс `fa-t-{имя}`.

| Имя | Шрифт | Размер / строка | Вес |
|---|---|---|---|
| `display` | Tektur | 40 / 44 | 600 |
| `title` | Tektur | 24 / 30 | 600 |
| `kpi` | Tektur | 28 / 32 | 600 |
| `section` | Plex Sans | 18 / 26 | 600 |
| `body-lg` | Plex Sans | 16 / 24 | 400 |
| `body` | Plex Sans | 15 / 22 | 400 |
| `table` | Plex Sans | 14 / 20 | 400 |
| `label` | Plex Sans | 14 / 20 | 500 |
| `caption` | Plex Sans | 13 / 18 | 500 |
| `id` | Plex Mono | 13 / 18 | 500 |

Tektur не используется мельче 20 px и для обычного текста.

### Радиусы

| Токен | px | Где |
|---|---|---|
| `radius-xs` | 6 | Минимальное вложение |
| `radius-sm` | 10 | Пункты списка, мелкие блоки |
| `radius-md` | 16 | Блок внутри карточки, textarea, меню |
| `radius-card` | 24 | Карточки |
| `radius-island` | 32 | Острова, баннеры, нижний лист |
| `radius-pill` | 999 | Кнопки, поля, чипы, вкладки |

Вложенный радиус равен внешнему минус отступ и не меньше 6 px. Пример: остров 32 с отступом 16 даёт вложенный блок 16.

### Тени

`shadow-xs`, `shadow-soft`, `shadow-card`, `shadow-lift`, `shadow-overlay`, `shadow-island`, `shadow-image`. Слоистые тени вместо жёстких рамок, свои значения для светлой и тёмной темы.

## Темы

```html
<html data-theme="light">  <!-- или "dark" -->
```

`data-theme` можно поставить на любой элемент. Без атрибута действует `prefers-color-scheme`. Обе темы собираются из одних и тех же имён semantic-токенов.

## Акцент продукта

Слой `product` переопределяет только группу акцента: `accent`, `accent-hover`, `accent-press`, `on-accent`, `accent-border`, `island-accent`.

| Слот | Состояние |
|---|---|
| `falcon` | Основной акцент (янтарь), переопределений нет |
| `vitrino` | Пустой слот под акцент Vitrino |
| `gold` | Золото брендбука `#D2A852`, оставлено для сравнения |

Включение: `<body data-product="gold">`. Чтобы добавить акцент продукта, заполните его слот в `tokens/tokens.json` и выполните сборку: проверка контраста применяется и к переопределениям.

## Проверка контраста

`npm run build` проверяет:

| Правило | Порог |
|---|---|
| Текст на фоне | 4,5:1 |
| Граница контрола | 3:1 |
| Кольцо фокуса (в том числе на островах) | 3:1 |
| Точка статуса | 3:1 |
| Текст и акцент на островах | по правилам острова |

Сейчас 201 проверка, 0 ошибок. Минимумы: текст 5,40, граница 4,24, точка статуса 3,56, остров 7,45. Отчёт: [`dist/contrast.json`](../dist/contrast.json).
