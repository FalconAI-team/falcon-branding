# Запуск и сборка

## Требования

- Node.js 18 или новее (проверено на 22). Проверить: `node -v`.
- Любой современный браузер.
- Git, если клонируете репозиторий.

Зависимостей нет: ни `npm install`, ни сборщика.

## Запуск localhost

```bash
git clone git@github.com:FalconAI-team/falcon-branding.git
cd falcon-branding
npm start
```

`npm start` поднимает локальный сервер на порту **8767** и открывает брендбук в браузере. Адрес всегда один:

```
http://localhost:8767/preview/index.html
```

Корень `http://localhost:8767/` перенаправляет туда же.

### Варианты запуска

| Команда | Что происходит |
|---|---|
| `npm start` | Сервер и открытие браузера |
| `npm run serve` | Сервер без открытия браузера |
| `npm run dev` | Сначала сборка `dist/`, затем сервер |
| `node scripts/serve.mjs --port 9000` | Другой порт |
| `node scripts/serve.mjs --open` | Сервер с открытием браузера, без npm |
| `PORT=9000 node scripts/serve.mjs` | Порт через переменную окружения |

Остановить сервер: Ctrl+C в терминале.

### Почему свой сервер, а не `python -m http.server`

Брендбук загружает файлы по относительным путям из соседних папок (`../dist`, `../assets`, `../fonts`), поэтому сервер должен отдавать корень репозитория. Скрипт `scripts/serve.mjs`:

- слушает только `127.0.0.1` (из сети недоступен), принимает запросы только к `localhost` и отдаёт лишь нужные папки: `preview`, `dist`, `assets`, `fonts`, `tokens`. Файлы вроде `.git` и `scripts` не отдаются;
- ставит `charset=utf-8` для HTML, CSS, JS и JSON (иначе русский текст превращается в кракозябры);
- отключает кэш (`Cache-Control: no-store`), поэтому правка видна после обычной перезагрузки.

Открывать `preview/index.html` двойным щелчком (через `file://`) нельзя: браузер блокирует загрузку JSON и модулей.

## Сборка

```bash
npm run build
```

Или без npm: `node scripts/build.mjs`.

Скрипт читает `tokens/tokens.json` и `src/`, проверяет контраст и записывает `dist/`. Если проверка не проходит, сборка завершается с кодом 1 и **ничего не пишет**, то есть в `dist/` не попадает сломанный результат. Что собирается:

| Выход | Для кого |
|---|---|
| `dist/css/falcon.css` | чистый HTML: шрифты, токены и компоненты одним файлом |
| `dist/css/tokens.css`, `fonts.css`, `components.css` | то же по частям |
| `dist/tailwind/theme.css` | Tailwind v4 (`@theme inline` на CSS-переменных) |
| `dist/css/shadcn-aliases.css` | необязательно: имена переменных shadcn/ui |
| `dist/js/falcon-tooltip.js`, `falcon-select.js`, `falcon-sheet.js` | подсказки, выпадающий список, нижний лист |
| `dist/flutter/falcon_theme.dart`, `pubspec_fonts.yaml` | тема Flutter и записи шрифтов |
| `dist/tokens.flat.json` | значения токенов для сторонних инструментов |
| `dist/contrast.json` | отчёт проверки контраста |

`dist/` хранится в git. Если вы меняли `tokens/` или `src/`, пересоберите и закоммитьте `dist/` вместе с изменениями.

## Как пользоваться брендбуком

Брендбук это приложение, а не длинная страница. Слева сайдбар с разделами, сверху тулбар.

| Элемент | Что делает |
|---|---|
| Сайдбар | Разделы. Кнопка внизу сворачивает панель в рельсу. Группа «Дополнительно» раскрывается |
| Ctrl K | Поиск по разделам |
| S, M, L | Размер сетки и содержимого карточек. Влияет и на заливку |
| Светлая, тёмная, системная | Переключатель темы |
| Раздел «Адаптив» | Живые окна на ширине телефона (390), планшета (820), ноутбука (1280) |
| Клик по цвету | Копирует hex. Shift копирует `var(--fa-...)` |

Разделы: Обзор, Цвет, Шрифты, Формы, Карточки, Элементы, Движение, Загрузка, Адаптив, Сокол, Иллюстрации, Контраст, Правила, Установка. Подробнее в [brandbook.md](brandbook.md).

## Решение проблем

**Порт занят.** Сообщение `Port 8767 is busy`. Запустите на другом порту: `node scripts/serve.mjs --port 8768`.

**Страница пустая или стили не загрузились.** Открыт адрес через `file://` или сервер запущен не из корня репозитория. Запускайте только через `npm start` или `node scripts/serve.mjs` и открывайте `http://localhost:8767/preview/index.html`.

**Вместо русских букв кракозябры.** Сервер не отдаёт `charset=utf-8`. Используйте `scripts/serve.mjs`, а не случайный сервер.

**Правки не видны.** Нажмите Ctrl+F5. Если правили `tokens/tokens.json` или `src/`, сначала выполните `npm run build`: брендбук читает `dist/`, а не исходники.

**Сборка падает с кодом 1.** Одна из цветовых пар не проходит порог контраста. В выводе указана пара и значение. Исправьте токен в `tokens/tokens.json` и повторите сборку.
