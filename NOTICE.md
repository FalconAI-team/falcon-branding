# Сторонние материалы

## Шрифты

Шрифты лежат в `fonts/` и распространяются по SIL Open Font License, Version 1.1. Тексты лицензий лежат рядом с файлами (`OFL.txt`).

| Шрифт | Правообладатель | Лицензия | Файл лицензии |
|---|---|---|---|
| Tektur | The Tektur Project Authors (https://www.github.com/hyvyys/Tektur) | SIL OFL 1.1 | `fonts/tektur/OFL.txt` |
| IBM Plex Sans | IBM Corp., зарезервированное имя «Plex» | SIL OFL 1.1 | `fonts/ibm-plex-sans/OFL.txt` |
| IBM Plex Mono | IBM Corp., зарезервированное имя «Plex» | SIL OFL 1.1 | `fonts/ibm-plex-mono/OFL.txt` |
| Source Serif 4 (только черновик 0.3, `next/`) | Adobe, зарезервированное имя «Source» | SIL OFL 1.1 | `next/fonts/source-serif-4/OFL.txt` |

Шрифты подключаются локально, запросов к Google Fonts нет. Файлы woff2 можно использовать в продуктах Falcon, сохраняя файлы лицензий. Для Flutter нужны TTF, которые берутся из тех же источников.
